# Vaultr Design System Integration

## Connection to MiroFish
The design tokens in this directory power the Vaultr platform UI at `fxarmstrong44-hash/mirofish`.

## Token Mapping
- `design-tokens.json` → `src/app/globals.css` (CSS custom properties)
- `component-specs.json` → `src/components/` (React component implementations)
- `style-guide.md` → Overall UI/UX guidelines

## Colors Applied
- Background: #0a0a0f (dark base)
- Gold accent: #c9a84c (primary brand)
- Glass effects: white/5-10% opacity borders and backgrounds
